# Zidane Books ko phone par app ki tarah lagana

Play Store ki zaroorat nahi. App seedha website se install hoti hai: apna icon, poori screen, aur phone par alerts.
Shart sirf yeh hai ke site **https** par khule (books.zidane.com.pk par SSL laga hua hai).

## Android (Chrome)
1. Chrome mein **books.zidane.com.pk** kholein aur login karein.
2. Upar **⬇ Install app** ka button aayega. Use dabayein. (Ya Chrome ka menu ⋮ → **Install app** / **Add to Home screen**.)
3. Home screen par laal **Z** wala icon aa jayega.
4. App kholein → menu → **My account & app** → **🔔 Turn on alerts** → **Allow**.

## iPhone (Safari)
1. **Safari** mein books.zidane.com.pk kholein (Chrome se nahi hota).
2. Neeche **Share** button → **Add to Home Screen** → **Add**.
3. Home screen se app kholein → **My account & app** → **🔔 Turn on alerts** → **Allow**.
   (iPhone par alerts sirf home screen wali app se chalte hain, iOS 16.4 ya naya chahiye.)

## Laptop / computer (Chrome ya Edge)
Address bar ke daayein taraf install ka icon aata hai, ya **⬇ Install app** button. App alag window mein khulti hai.

## Kya milta hai
- Har banda apne phone par apne alerts paata hai: sawal, nayi Job, material ready, approval, payment
- Alert dabane par seedha wahi invoice ya Job khulta hai
- Bill ki photo ke liye camera seedha khulta hai (Supplier bill → Fill from bill photo)
- Home icon dabaye rakhne par shortcuts: Orders Inbox, New Job, Supplier bill

## Note
- Figures hamesha live aate hain, phone mein data save nahi hota. Internet na ho to app "No internet connection" dikhati hai.
- Update khud aa jata hai. Server par naya version lagte hi app agli dafa khulne par naya version dikhati hai.
- Alerts band karne hon to: **My account & app → Turn off**.
